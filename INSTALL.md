# Installation Guide

This guide will help you install and set up the project on your local machine.

## Prerequisites

Before you begin, ensure you have met the following requirements:

- This should run on all major operatiing systems including Windows, macOS, and Linux. You might face problems when
  using something else
- **php 8.2.12** or higher. (I'm not sure about what's really needed, but this is what I'm using)
- A web server like **Apache** or **Nginx**. (On nginx you might want to implement the .htaccess rules manually)
- **MySQL** or **MariaDB** database server. (MariaDB 10.4.32 used for development)
- **Composer**
- **Git**
- The **php imagick extension** ideally installed from [here](https://packagist.org/packages/imagick/imagick) downloaded
  via [pie](https://github.com/php/pie)
- **ffmpeg** installed and accessible from your system's PATH.
- A **Database management system** (I used phpMyAdmin during development, but it anything can be used)
